# Sales Data Analysis

## Project Overview
This project analyzes sales data using MySQL, Microsoft Excel, and Power BI to identify sales trends, product performance, and regional revenue.

## Project Objectives
- Calculate total sales revenue.
- Analyze sales by product and region.
- Identify the highest-revenue products.
- Analyze monthly sales trends.
- Present findings through tables, charts, and dashboards.

## Tools Used
- MySQL — Data querying and analysis
- Microsoft Excel — PivotTables and charts
- Microsoft Power BI — Interactive data visualization

## Key Findings
- **Total Revenue:** 602,400
- **Total Quantity Sold:** 90 units
- **Top Revenue Product:** Laptop
- **Highest-Revenue Region:** South

## Project Structure
- `dataset/` — Dataset documentation
- `sql/` — SQL queries and analysis
- `excel/` — Excel sales analysis and charts
- `powerbi/` — Power BI dashboard documentation and report

## Skills Demonstrated
SQL querying, data aggregation, PivotTables, data visualization, and business data analysis.
