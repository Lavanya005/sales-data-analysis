# Excel Sales Analysis

## Objective
Analyze sales data using Microsoft Excel.

## Analysis Tasks
- Calculate total sales revenue.
- Compare sales by product.
- Analyze regional sales performance.
- Calculate monthly revenue.
- Identify the highest-selling products.
- Create PivotTables and charts.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts
- Formulas

## Expected Output
An Excel workbook containing sales analysis, summary tables, and charts.
